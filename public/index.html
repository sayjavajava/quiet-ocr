QuietOCR

Pull text out of an image, entirely in your browser. This page loads its own code from the network — but once it has, your image is never uploaded anywhere. Recognition runs locally, in WebAssembly, on your machine.

    Recognized text

    No account, no server, no telemetry. Source on GitHub. Sibling project: OffGridPDF (fully offline PDF tools — a stricter, zero-network guarantee this project does not make; see this repo's README for the difference).
